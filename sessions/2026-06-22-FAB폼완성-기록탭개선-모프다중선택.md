## Flutter

### 신규 기능

**FAB 기록 폼 (fab_record_sheet.dart)**
- `simpleForm` 스텝 추가 — 피딩 외 5개 타입 지원
- 몸무게: g 숫자 입력 + 메모
- 청소: 전체/부분/물갈이 칩 선택 + 메모
- 메모: 텍스트 영역 + 병원메모 체크박스 (VET 태그)
- 메이팅: 내 개체/외부 개체 토글, 내 개체 인라인 목록, 외부 텍스트 입력 + 메모
- 산란: 알 총 개수 + 유정란 수(선택) + 메모
- 완료 화면 메시지 기록 종류별 분기

**모프 다중선택 (pet_form_screen.dart, pet_models.dart)**
- `Pet.morphs List<Morph>` 추가 (N:N)
- `CreatePetRequest.morphIds List<int>` 전환 (`morphId` 제거)
- 폼 칩 다중 토글 선택
- 개체 수정 시 `pet.morphs`로 직접 초기화
- `pet_info_grid.dart`: 모프 목록 쉼표 구분 표시

### 버그 수정

**종 선택 대분류 레일 (species_bottom_sheet.dart)**
- 기존: 단일 문자 키 `G/L/C/S/T/F/N` 비교 → 레일 미표시
- 수정: DB 실제 값 `GECKO/LIZARD/CHAMELEON/SNAKE/TURTLE/FROG/NEWT` 비교

**기록탭 (record_tab.dart)**
- "N시간 전" 텍스트 → 카테고리 색상 `>` 화살표 아이콘 (항상 표시)

**캘린더 바텀시트 피딩 (dashboard_tab.dart)**
- `_translateFeedingSummary()`: CRICKET → 귀뚜라미 등 Flutter 레이어 변환
- 메모 별도 줄 → `summary  ·  메모` 인라인 표시

**Pet.morphs null 안전성 (pet_models.dart)**
- `const Pet()` → `Pet()` + initializer list `morphs = morphs ?? const []`
- `fromJson` morphs 파싱 try-catch fallback `<Morph>[]`
- `Morph.fromJson` id/speciesId num 캐스팅 안전화
